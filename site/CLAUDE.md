# site/ — German history website (generated from the knowledge base in `../`)

The full brief is `../WEBSITE_BUILD_PROMPT.md`; the agreed plan is `PLAN.md`. Rules that apply to every change:

- **Never modify anything outside `site/`** (the knowledge base is read-only), except `../.claude/launch.json`.
- **The Markdown is the single source of truth.** Page content comes from `src/content/generated/*.json`, generated by `scripts/build-content.mjs`. Never hand-type or paraphrase historical text into templates.
- Any new wording (teasers, UI prompts, alt-text additions, image-type or theme classifications) must be logged in `CONTENT_TRACE.md` with its source file + section. No new historical facts.
- Keep epistemics visible: confidence badges, CONTESTED labels, source levels A–F, debates, and "constitution said vs power worked".
- Images: always show caption, creator, date, holder and licence plus a source link. No zoom, pan, colourisation or "enhancement" on photographs. Propaganda and official art get a "Read this image critically" note.
- Sensitive eras (Nazi period, Holocaust, colonial violence, GDR repression): calm register, no points, streaks or playful motion.
- The build must fail loudly when a file breaks the template (see `scripts/build-content.mjs`).
- Ask before downloading files (including `scripts/download-images.mjs` and Playwright browsers), publishing or deploying.

Commands (run from `site/`): `npm run content` · `npm run dev` · `npm run build` · `npm run qa`.
