# Video Sources (YouTube, broadcasters, lecture series)

*These are **leads and explanatory aids**, not evidence. No key claim in this knowledge base rests solely on a video. Channels/series were identified via search; individual episodes were not audited for accuracy in this project — treat them as Level C–D and verify against the written sources in `bibliography.md`.*
