# Source Audit

## Checklist applied to every major claim

- [x] Supported by a credible source
- [x] Ideally corroborated independently (different source *types* where possible)
- [x] Source type identified (A–F)
- [x] Primary/secondary distinction clear
- [x] Potential bias considered (e.g., civic-education framing; partisan contemporary reports; perpetrator records)
- [x] Contradictory evidence searched for (revisionist/critical positions sought for each major narrative)
- [x] Historiographical disagreement identified where relevant
- [x] No unsupported causal claim (causal claims flagged as CONTESTED where debated)
- [x] No anachronistic terminology (see `01_RESEARCH_METHOD.md §5`)
- [x] No confusion of modern Germany with historical German territories
